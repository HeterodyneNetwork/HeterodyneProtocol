# Architecture Decision Records

ADRs are non-canonical, point-in-time records of decisions proposed for the
Heterodyne specification. The current protocol authority is the versioned
specification family and its normative registries, schemas, release metadata,
and conformance vectors.

Proposed ADRs are authored in this directory. The branch or pull request that
accepts an ADR must also contain every corresponding specification and
normative-artifact change. Before merge, mark the ADR accepted and move it to
[`archive/`](archive/). Merge only when the specification stands on its own.

If an ADR and the specification disagree, the specification governs.
