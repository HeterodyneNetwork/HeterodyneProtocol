# Heterodyne

> Nostr identity, Matrix transport. A decentralized social network protocol
> that publishes Nostr events into Matrix rooms — public, community, and
> end-to-end encrypted — to combine cryptographic authenticity with
> ratchet-grade group privacy and stateful room governance.

This repository currently contains background research only. Protocol
specification and reference implementation are forthcoming.

See [`CLAUDE.md`](CLAUDE.md) for the project mission and repo map, and
[`research/INDEX.md`](research/INDEX.md) for the topic-keyed research index.
